# Public-family focus icon prompts

All prompts used Codex built-in `image_gen`. Each request specified a centered HOI4 focus emblem, painterly 1930s game-art texture, strong dark outline, no text/watermark/UI, and a flat `#00ff00` chroma-key background for transparent extraction. The six renders that arrived with a green background were keyed locally; the remaining renders already contained alpha.
