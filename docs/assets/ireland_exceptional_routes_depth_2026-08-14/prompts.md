# Ireland exceptional routes art prompt log

Generation date: 2026-08-14. All source art was created with the official image-generation workflow. No archival photography or real-person likeness was used. The canonical reference root was reviewed before generation; focus work matched `vanilla_reference/icons/national_focus`, action work matched `icons/decisions`, mission work matched `icons/missions`, report work matched `event_art/report`, and flag work matched `flags`.

## Shared style constraints

Every prompt requested one central readable subject, strong silhouette, jewel-toned period-fantasy colour, painterly/embossed HOI4 icon treatment, high value contrast, no letters, no numerals, no UI, no border, no watermark, and no split-panel composition. Focus prompts requested a transparent-ready black surround for later alpha cleanup. Decisions and missions requested a compact medallion/object that remained legible at 32x32. Reports requested a distinct sepia 1930s documentary scene with no readable signage. Flags requested a flat heraldic field with a single central emblem and no lettering.

## Event report prompts

Events 438–460 each received a separate prompt for a period documentary report scene, covering royal custody, party-crown rupture, provincial convention, confederal budgeting, fifth-seat dispute, rival administrations, Fian mobilisation, veil-site incidents, court hearings, restitution, containment review, and the final sovereignty/convergence outcomes.
