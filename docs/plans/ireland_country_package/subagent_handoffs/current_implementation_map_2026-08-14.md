## Primary findings

1. The current source is a substantial foundation, not an empty country. The focus parser currently sees 218 authored Ireland focuses and 226 connectors in `ireland_focus_tree.txt`; the previous frozen documentation describes 215, so the current uncommitted campaign-depth tranche has added three focuses. It retains exactly three opening roots and three shortcuts.

2. A concurrent tranche has made the territorial lane more visible, but it is not integrated yet. The current chain is:

   `ireland_unfinished_national_question` → `ireland_border_and_atlantic_dossier` → `ireland_test_the_state_instruments` → `ireland_define_the_national_question` → `ireland_authorise_reunification_instruments` → one family method → one family resolution → Atlantic policy.

   `ireland_national_settlement` sets `ireland_territorial_lane_revealed`, so the lane can be shown after Settlement. The new cards grant 5 Army XP + 5 Navy XP, 5 Command Power plus a named Border Atlas operation, and a one-use Support Technology research bonus. This is a better player-facing lead-in than the former detached flag-only root, but the three new focus icons are not registered in any `.gfx` file, so the current MCP focus inspect/render fails on all three.

3. The five family methods and the larger territorial tail are materially present but remain visually and mechanically uneven. The methods mostly deliver a decision unlock plus a 2–5% stability change, 250 rifles, or ledger flags; resolution cards are primarily flags. The real operations are hidden in decisions and missions, so the focus tree still communicates “preparation” more clearly than payoff. Existing family gateways are scattered at `(-16,4)`, `(-12,3)`, `(-8,7)`, `(-6,10)`, and `(-4,4)` rather than forming the readable post-Settlement choice band required by the new canonical spec.

4. The same-block prerequisite semantics matter. The offline focus page confirms that multiple `focus =` entries in one `prerequisite` block are OR, while separate `prerequisite` blocks are AND. Therefore `ireland_atlantic_ambition`'s five resolution entries are an intentional “whichever family was selected” OR and are not an automatic dead end. Conversely, `ireland_atlantic_settlement_concluded` currently places `ireland_local_rights_charter`, `ireland_protectorate_statutes`, and `ireland_integration_review_commission` in one block, making them OR. Its `available` trigger checks relevant holding records but does not require all three outcome focuses. That under-gates the conclusion against the canonical requirement that all settlement outcomes and relevant holdings be resolved.

5. The current Atlantic expansion implementation contains a confirmed unresolved-event gap. `ireland_territorial_claim_wales` launches `ireland_territorial_diplomacy.17` and `ireland_territorial_claim_cornwall` launches `.21` (`common/decisions/ireland_expansion_decisions.txt:547-652`), but `events/ireland_territorial_diplomacy_events.txt` defines only `.1` through `.16`. No `.17` or `.21` source or localisation reference was found. Those operations set `ireland_wales_demand_pending`/`ireland_cornwall_demand_pending` and `ireland_territorial_diplomacy_active`, so a player can enter a stuck diplomatic state unless another cleanup path intervenes.

6. The broader package has many reusable active systems: 14 progressively revealed decision categories; Parliament, Northern Settlement Ledger, and Concealed Evidence scripted GUIs; a daily IRE-only runtime and monthly recomputation; mission capacity/cancel/timeout/result bookkeeping; route profile and identity synchronization; five public family cabinets; 45 advisor roles; seven industrial concerns; Ford Cork and Harland & Wolff MIOs; and a large event/flavour package. The missing depth is integration and route-specific consequence, not raw file count.

7. Documentation has two incompatible authorities. The new `docs/specs/ireland_country_package/` package explicitly supersedes focus-count/flag-count completion claims and calls for connected navigation, concrete payoffs, route failure/recovery, and 1946–1951 conclusions. Older completion records still claim a frozen 215-focus package is complete with no blockers. Several older handoffs also contain 188/215 historical snapshots. The parent should use the new country-package spec as authority and reconcile or mark old completion records after implementation.

## Existing patterns

### Navigation and disclosure

- The tree deliberately keeps the opening to `ireland_state_still_defined`, `ireland_economic_war_review`, and `ireland_defence_estimates`, with exactly three shortcuts. This should be retained.
- `allow_branch` is used for political families, concealed routes, Marine Service, the new territorial lane, and postwar offices. Runtime calls to `mark_focus_tree_layout_dirty` are already present, so newly revealed branches can be refreshed in-session.
- Decision categories are progressively revealed by scripted triggers rather than dumped at game start. The Northern Ledger and Concealed Evidence Ledger are good patterns to reuse, but there is no equivalent territorial holding ledger.

### Active systems and material gates

- Existing decisions use dynamic/fixed constants, timed removal, `cancel_trigger`, `cancel_effect`, `complete_effect`, `timeout_effect`, operation capacity, and exact requirement tooltips. The territorial claim decisions check peace, Dáil/readiness, manpower, infantry/support equipment, convoys, fuel, command power, target controller/faction status, strength ratio, and naval access.
- Industrial decisions currently deliver infrastructure, factories, motorized equipment, trains, convoys, transport aircraft, fuel, dockyards, or XP. They are materially useful, but most are uniform 25 Political Power/35-day contracts with no factory-time, equipment, resource, or fuel input; this is exactly the “PP shop” risk called out by the canonical spec.
- Mission lifecycle helpers in `ireland_effects.txt` and `ireland_runtime.txt` track full/partial/failure/escalation/cancellation, capacity, pause/cleanup, and recovery. This gives the parent a reusable base for family-specific crises rather than a new generic counter.

### Target diplomacy and cleanup

- The `.1-.16` event chain saves requester, controller, and state as global event targets, handles accept/counteroffer/refuse/stale paths, applies a 180-day cooldown, and clears targets via `ireland_clear_territorial_diplomacy_targets`.
- The missing `.17`/`.21` event references show that this pattern was not carried through to Wales/Cornwall. The parent should extend the same target/cleanup contract before adding further Atlantic claims.

### Route identity and industrial identity

- Public family focuses set durable family flags and open cabinet pools; route runtime synchronizes advisors, leaders, offices, spirits, and cosmetic identity. The three persistent spirit families are an existing route-identity scaffold.
- Seven concerns plus Ford/H&W MIOs provide a good basis for making route-specific economic and military choices matter. Current territorial focuses do not consistently connect these institutions to their payoff, so a reward audit should map each card to an immediately named operation, institution transformation, or capability.
